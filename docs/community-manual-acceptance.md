# 图纸广场：用户人工验收

## 本次交付边界

2026-10-09 已执行豆屿社区增量迁移、启动更新后的本机服务与小程序编译，并完成截图问题的模拟器基础检查。下方保留完整人工验收清单，勾选框不代表已通过；未运行全量测试/lint，未代替用户发布真实作品或确认手机相册下载。

当前工程为 uni-app Vue3 + Node.js/Express + MySQL。仅操作本机 `127.0.0.1:3306/bead_island` 和应用账号 `bead_island_app`；不改 bless 的 3307、3000，不重置密码，不清库。旧 uniCloud 目录保留作历史资料。

## 重新启动时使用

在项目根目录打开终端，MySQL 3306 实例须已运行。先停止现有豆屿后端，然后执行：

```sh
cd /Users/jkliang/Desktop/pindou
npm --prefix backend run migrate:community
npm --prefix backend run dev
```

另开一个终端：

```sh
cd /Users/jkliang/Desktop/pindou
npm run dev:mp-weixin
```

微信开发者工具打开 `/Users/jkliang/Desktop/pindou/dist/dev/mp-weixin`。不要导入旧 build 目录；不要修改 dist 代替源码。根目录的 `npm start` 是旧设计原型，不是 API。

迁移入口读取 `backend/.env` 的连接目标、以及 `~/.local/etc/mysql/private/root-client.cnf` 的本机管理员配置。文件不是应用连接密码；迁移不会改任何密码。不再次运行 `provision:local`。迁移脚本可重跑，遇到已有字段跳过，已有表保留；失败不等于完全回滚，按说明修复连接或权限后再运行。

如管理员配置在其他位置，可在同一命令前设置 `MYSQL_ADMIN_CNF=/绝对路径/root-client.cnf`；脚本仍只允许 root、127.0.0.1、3306 和 bead_island，不能用此脚本部署远程服务器。

后端配置缺少 `WECHAT_APP_SECRET` 时真实登录/私有上传不可用；如修改 `backend/.env`，手动 Ctrl+C 后重新启动后端。新增服务必须完成本次迁移再运行，旧库缺字段会使相关接口失败。

电脑模拟器默认 API 为 `http://127.0.0.1:3001`，本机 HTTP 调试仅在开发项目临时关闭合法域名校验。正式 `src/manifest.json` 保持安全校验开启。真机应使用同 Wi-Fi 下电脑局域网地址，并按 `local-startup.md` 配置，不能使用手机自身的 127.0.0.1。

## 1. 简洁页面与固定导航

- [ ] 首页只显示图纸广场、搜索、最热/最新和发布入口，没有灵感、营销文案或重复品牌说明。
- [ ] 发现、转图、色号、作品都是真实 tab；切换转图保留 tabBar，手势不会误退小程序。
- [ ] 首页搜索/排序条与顶栏保持固定；各页上下滚动时状态区和导航不跟随内容移动。
- [ ] 我的作品是账号入口、全部/在拼/已完成、双列作品卡；没有统计大卡、同步按钮、本机已保存或已同步字样。
- [ ] 卡片可打开跟拼；更多操作可查看图纸、修色、导出、发布与删除。删除已有公开作品时说明需另行下架。

## 2. 自定义弹层与登录名称

- [ ] 游客可浏览、查看和下载公开图纸。上传个人照片、发布及修改账号资料要求登录。
- [ ] 登录、设置名称、确认删除/更新/下架、操作列表、忙碌反馈及 toast 使用奶油/绿色自定义组件。
- [ ] 取消登录不调用选图、不上传；跳过名称设置使用稳定默认名称，重新打开仍一致。
- [ ] 作品页点账号名称可修改；发布页只有作品名称，没有昵称输入框，署名取当前账号名称。
- [ ] 空白名称、控制字符、超过 24 个 Unicode 字符被拒绝；正常汉字与 emoji 可保存。
- [ ] 自定义弹层打开时图纸查看器不能拖动或缩放；取消、重入、切 tab、返回均能结束等待，不出现旧弹层影响新页。
- [ ] 相册权限请求/系统设置/系统图片预览仍为微信平台界面，不伪装成自定义权限。

## 3. 保存与登录隔离

- [ ] 断网时个人作品、修色、跟拼行进度仍保留；恢复网络且登录有效时后台保存，不需点击同步。
- [ ] 连续修改/完成行，旧网络响应不覆盖较新的图纸/进度。
- [ ] 首次登录后恢复自己的已有作品；微信账号变化时阻止本机混用，不直接把另一账号作品认领过来。
- [ ] 会话过期后的受保护操作按既有刷新逻辑处理；游客访问不自动发起登录。
- [ ] 从广场开始拼，生成新的个人作品、零完成进度，不继承作者原图，不能直接作为自己的原创再次发布。
- [ ] 私有作品与原图只能由所属账号读取；不能通过公开社区 ID 得到原图、owner、openid、私有来源 ID、进度或磁盘路径。

## 4. 发布、更新与下架

- [ ] 先保存一份自己的图纸，再从首页＋或作品更多进入发布；标题限制 1–50 个 Unicode 字符。
- [ ] 断网/保存未完成不能假报发布成功；保存期间发生内容冲突或图纸变化时要求重新选择。
- [ ] 同一源作品并发/重复发布相同内容只有一份帖子；内容不同提示确认更新，而不是重复创建。
- [ ] 更新图纸保留下载总数；名称修改后署名和作者搜索使用新名称。
- [ ] 不能修改、下架别人的帖子；作者下架后访客详情、缩略图与下载不可继续访问。
- [ ] 删除个人作品不会自动删除已发布快照；在公开详情的作者操作中可另行下架。

## 5. 搜索、瀑布流与动画

- [ ] 首页已初始化 10 份「豆屿图纸」原创示例，可查看真实格点、MARD 用量、跟拼和导出；个人作品列表不自动加入这些示例。
- [ ] 首次列表和触底分页请求均使用 `limit=10`；通过游标连续取下一批，无更多时停止，末页允许少于 10 条。搜索/切换排序从第一页重新查询。
- [ ] 可按作品名称和账号名称搜索，清空恢复列表；最热按下载总数优先，最新按发布时间。
- [ ] 相同下载量再按发布时间和 ID 稳定排序；最热排名在新查询/刷新时读取后端数据。
- [ ] 图纸比例不同，左右列自然错位，不是等高网格；加载下一页不重复同一公开 ID。
- [ ] 快速切换搜索/排序后旧请求返回，不混入新列表；旧分页失败不污染新的 loading/error。
- [ ] 新卡片从下到上错峰入场，轻微越位再回弹；滚动、数字刷新和再显示已有卡片不重播动画。
- [ ] 将 community-gallery 的 reduceMotion 属性设为 true，或在支持系统减少动态偏好的设备上，卡片直接落位；无图纸、无搜索结果、断网有简短空态/重试。

## 6. 高清图纸、方向与计数

- [ ] 公开详情、材料列表和大图单元格显示 MARD 代码，如 M12/G3/F17/B25，不显示 HEX。
- [ ] 详情查看器双指缩放、单指平移及 ±/复位正常，缩放不来回闪动；关闭详情后保留查看位置。
- [ ] 缩放数字与实际格子尺寸同时变化，复位恢复全图居中；详情只出现一张图纸，材料列表独立滚动，不被画布遮挡。
- [ ] 导出可选正面/左右镜像；选镜像只翻图案，坐标、代码和用量文字保持正向。
- [ ] 相册得到 PNG 原尺寸高清图，包含每格色号、四边坐标、红色分区线和完整用量。
- [ ] 拒绝相册权限、取消保存、编码失败不能增加下载量；权限重试保存成功才确认。
- [ ] 每次成功保存发起一次确认；同一意图重试/并发上报只增加一次，复制到我的作品不计相册下载。
- [ ] 保存成功但确认断网，在意图有效期内恢复可补确认，不重复保存文件；相册成功反馈不因确认失败变成导出失败。
- [ ] 错作品 ID、伪凭据、过期或已下架意图不增加下载量。缓存不足且确认断网，可能无法保留补报队列，不应误报相册保存失败。

## 数据与运营说明

新表为 `bead_public_works`（公开图纸快照、标题、下载量）、`bead_public_downloads`（10 分钟确认意图）。用户表增加 `display_name`，个人作品表增加 `origin_public_id`。私人响应中的 `publishedId` 仅供本人管理提示，不是公开原图链接。

原图继续在 `backend/data/private-images` 私有目录；公开缩略图是服务端按固定 MARD 色卡绘制的 PNG，位于 `backend/data/community-thumbnails`。备份同时包含数据库和两类图片目录。更新或提交结果不确定时可能保留旧/孤立衍生图，清理前要对照数据库引用，不能直接删整个目录。

下载统计是客户端报告的「系统相册保存成功」次数：不是独立人数，不是服务器能验证手机回调的防刷证明。确认凭据幂等、短期有效并有频率限制；公开运营仍需监控、审核、举报、用户协议/隐私指引、HTTPS/合法域名、备案及存储权限配置。本轮不含这些生产部署，也没有接 OSS。
