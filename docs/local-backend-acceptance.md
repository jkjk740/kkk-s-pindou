日期：2026-10-08。代码与专用数据库配置已实施；按用户要求，代理没有运行测试、lint、构建、接口探针或真机验证。以下由用户自行执行，不能视为已经通过。

## 1. 配置与运行

1. 填写 `backend/.env` 的 `WECHAT_APP_SECRET`，不要改 DB_PORT=3306、DB_NAME=bead_island、DB_USER=bead_island_app。专用密码已经生成，服务不使用 root。
2. 终端一运行 `cd /Users/jkliang/Desktop/pindou/backend && npm start`。
3. 终端二运行 `cd /Users/jkliang/Desktop/pindou && npm run dev:mp-weixin`，或 HBuilderX 重新运行当前 uni-app CLI 工程。
4. 微信工具导入 `dist/dev/mp-weixin`，不是旧 `dist/build/mp-weixin` 或源码根目录。不要直接修改产物。
5. 手机联调：电脑与手机同一 Wi-Fi，将 backend/.env 的 HOST 设为 0.0.0.0，在根目录 `.env.local` 设置 `VITE_API_BASE_URL=http://电脑局域网IP:3001`，重启后端及前端编译。不能用手机的 127.0.0.1 访问电脑。不要将数据库端口暴露公网。
6. 微信后台隐私保护指引与实际功能一致：选图、原图私有上传存储、相册保存。本机 HTTP 需要工具的临时开发配置或受控 HTTPS 调试入口；正式版不关闭合法域名校验。

## 2. 本机与账号

- 游客可使用示例、保存、跟拼和导出。首页/转图页“换图”均须先登录，拒绝登录不打开相册、不覆盖草稿。
- 原图只在上传成功后创建个人草稿。取消相册、网络失败、超大图片时，旧作品和进度保持。
- 从系统相册正常返回能继续；上传中切 tab、打开另一示例，旧回调不能覆盖新草稿。
- 缺少/错误 AppSecret、无效微信 code 和过期令牌不会假登录。过期最多自动续期一次。
- 登录账号改变时提示备份与清理，不把同一个本机库静默归给新账号；换 API 地址不能把旧令牌发往新服务。
- 保留老本机作品。新后端首次同步标为待同步；仅在后端确认该账号没有同 id 记录时按 revision 0 创建；出现真实冲突保存本机副本。

## 3. 后端权限与持久化

- 用 MySQL 客户端连接 `127.0.0.1:3306`、bead_island_app 和 backend/.env 专用密码，数据库选择 bead_island。另一个工程的 3307/myapp 不变。
- 图纸同步后 users/works 存在相应记录；原图上传后 images metadata 与私有文件对应。重启服务后仍能读取。
- 无令牌上传/读取应拒绝；用户 B 不能读用户 A 的图纸和原图；不存在/不属于当前用户的 sourceImageId 不可保存。
- 并发保存同 revision 只有一个获胜；删除重试幂等；分页包含没有 pattern 的 tombstone；同步时继续编辑，新内容不能被旧快照覆盖。
- 上传只接受实际有效 JPEG/PNG/WebP 单帧。伪扩展名、动画、多文件、>10 MiB、>20MP 均拒绝；并发上传不能突破每用户 100 MiB 配额。
- 原图没有公开 URL。preview 先鉴权下载到临时文件，再调用原生预览。响应不含 SQL、stack、私有路径、openid 或密钥。
- 原图上传成功不代表图纸已同步；“作品 → 同步作品”才保存云端图纸/进度。删除作品不会主动清空原图目录。

## 4. 转图与高清导出

- 点击“转图”是真实 tabBar 页，四个 tab 持续显示；从跟拼“修色”返回使用 switchTab。工具栏/面板不覆盖 tabBar；真机检查安全区。系统根页侧滑可能退出微信小程序，恢复 tabBar 不保证能拦截系统返回。
- 主导出按钮和材料清单都打开同一方向面板，默认正面；镜像只左右翻转格子，色号/标题/四边坐标保持正向，原 cells/用量/完成行不变。
- 相册 PNG 白底、每格 40px：名称、实际格数/色数/总量/方向、四边每格坐标、细灰网格、5 格红线/10 格加粗线、底部材料清单；不包含参考图的作者署名或社交页面。
- 选非对称图纸对比正面/镜像；检查 24 色、60 字长标题、64×64、1×64 等长条图纸。标题最多 3 行，过长省略但详情保留完整名字。
- 实际查看相册文件像素尺寸与代码可读性，不用缩略预览代替；输出最多 12MP，不暗乘手机 DPR。
- 导出有准备/绘制/编码/保存阶段、重复点击锁；导出中不能修改图纸。只有相册保存成功回调才提示成功。
- 拒绝相册权限后有主动设置按钮；设置完成重试同一张 PNG，不强迫跳转、不假成功。取消保存、断网与编码错误要结束 loading 并可重试。

## 5. 跟拼和详情

- 图纸支持双指 1×–6× 连续缩放、单指拖动、±、百分比和复位；底图 codes 至少 24 输出像素/格。
- 默认轻点打开同页全屏详情；只有开启“点图选行”后才点击切换行。底部完成按钮单独改变进度。
- 双指变单指、拖动后抬手、长按不能误选行或完成进度；放大和拖动后点格子对应正确行。
- 内联/详情共享 pose，关闭详情不重置缩放或进度；原图预览回来仍保留详情和进度。
- 详情有尺寸、色数、豆子总数、材料数量；有关联原图时仅登录账号可预览。断网/授权失败提示，不影响已保存图纸。
- iOS 与 Android 都检查原生 Canvas、movable-view、层级和手势；拖动是即时操作，无装饰性延迟动画。
