## 上传并设置体验版

公网入口已启用，下面的微信上传与后台设置仍由用户操作：

1. 在微信开发者工具导入上述 **`dist/experience-ip/mp-weixin`**，确认 AppID 正确，不要误传普通开发输出 `dist/dev/mp-weixin`。
2. 登录有上传权限的微信账号，上传此版本，备注“临时 IP 体验，手机需开启调试”。
3. 在小程序后台找到刚上传的开发版本，设为体验版，并添加获邀者为体验成员，保存体验二维码。

当前自动化工具不能操作微信后台网址，上述后台步骤由用户自行完成。上传体验版不代表正式发布。

## 体验者手机操作

1. 使用已添加为体验成员的微信账号扫描体验二维码。
2. 在小程序右上角菜单中开启“开发调试”或“调试”，按提示确认，再退出并重新进入小程序。
3. 重新登录一次后体验。服务器使用了新的 SESSION_SECRET，之前的登录令牌可能已经失效；无需删除本地草稿。

这份产物的 `project.config.json` 为 `urlCheck=true`，私有开发工具配置为 `urlCheck=false`。私有配置只影响本机开发工具，**不能代替每位体验者在手机上开启调试**。未开启手机调试时，HTTP/IP 请求可能被合法域名和 HTTPS 校验拦截。

如果当前客户端菜单没有调试入口，先确认该微信账号具有体验成员权限，并使用最新微信客户端，再实际验证可用性；不保证所有客户端版本都有相同菜单或均支持该临时方式。入口不可用时应等待正式 HTTPS 地址，不关闭正式构建保护，也不让体验者连接 Mac 的 `127.0.0.1`。

体验者直接访问云端公网入口，不依赖开发者电脑是否开机、SSH 隧道是否保持连接。真实手机登录、作品操作及图片上传下载仍需实际验收；本次构建成功不能代替这些验收。

## 备案通过后改用 HTTPS

按 [阿里云发布手册](./aliyun-publishing.md) 的“备案通过后切换正式 HTTPS”完成 `api.tpejocq.cn` 的 DNS、证书、Nginx 及微信 request／uploadFile／downloadFile 合法域名配置，再显式使用 HTTPS 地址生成正式构建。确认新体验包可在手机关闭调试的情况下使用后，撤下临时 IP HTTP 入口及对应 80 入站规则；保留正式证书验证或 HTTP 跳转确实需要的规则，以当时实际配置为准。

HTTPS 可用后使用新的体验包，体验者无需开启手机调试。AI 仍单独保持关闭，启用和付费调用另行处理。
