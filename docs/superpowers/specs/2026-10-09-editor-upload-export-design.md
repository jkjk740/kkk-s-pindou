# 转图初始页与导出方向

用户已在当前会话确认设计图并要求开发。

- 新启动不创建默认猫咪草稿。转图 tab 显示奶油白拼豆背景与「上传图片」按钮，保留固定顶栏和 tabBar。
- 登录、选图、原图私有上传和本机转图沿用现有流程；取消不替换当前作品。转图成功后显示参数、修色、导出和保存。
- 显式打开已保存的作品仍进入编辑器；本次会话已经选择的真实草稿可以保留，不把切换 tab 当作清空操作。
- 导出立即打开自定义底部弹层，默认「正面」，可选「左右镜像」。预览只镜像图案，最终 PNG 的文字和 MARD 色号保持正向。
- 保存相册之前绘制高清 PNG，包含坐标、色号、用量；生成和保存期间显示进度并阻止重复操作。失败留在弹层内，可重试；权限拒绝提供设置入口。
- 修正导出事件绑定。导出预览使用普通图片，不在动画弹层里嵌套原生 canvas。
- 不修改后端契约、不迁移或清理数据库、不触碰 bless、不给正式配置关闭域名校验。
- 按用户既有要求不运行测试或 lint；完成后更新本项目开发编译和启动状态，真机相册验收交给用户。
