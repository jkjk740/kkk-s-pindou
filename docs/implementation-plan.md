# 豆屿设计原型实施计划

目标：交付五个核心页面的高保真设计、可操作原型和独立 PNG 设计图。

技术：原生 HTML / CSS / JavaScript / Canvas。无需生产依赖。设计规范见 design.md。

- [x] 建立统一设计变量、手机预览壳、微信导航和五页面布局。
- [x] 绘制原创像素小猫、花朵和咖啡图案，建立图纸 Canvas 渲染和色号匹配。
- [x] 串联本地图片导入、尺寸与颜色调节、色卡搜索、修色、导出、保存与跟拼恢复。
- [x] 制作 UI 总览画板、UX 流程画板、逐页 PNG。
- [x] 在移动宽度检查裁切、键盘、弹层、文件上传、透明背景和本地保存；实际运行转换和导出后交付。

验证记录：10 项浏览器功能检查通过，覆盖 320 / 375 / 393 / 430 px 的五页横向适配。另已实际渲染检查设计总览、UX 画板和逐页 PNG。设计总览中 25% 为示例进度，正常新图纸从 0% 开始。

文件边界：index.html 为预览入口，styles.css 为统一样式，app.js 为页面和交互，art.js 为原创图案和图纸算法，data/mard.json 为参考色卡，board.html 为设计总览，exports/ 为设计图片。
