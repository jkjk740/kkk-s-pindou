# 豆屿 · 微信拼豆小程序 UI / UX 设计

设计日期：2026-10-01。暂定名称：豆屿 / BEAD ISLAND。面向希望把喜欢的图片变成可实际制作图纸的拼豆爱好者，默认照顾第一次制作的人。

## 产品主线

选一张图片 → 设置图纸大小和颜色数量 → 自动匹配品牌色号 → 检查每色用量 → 保存图纸或进入跟拼模式。

首屏无需登录。默认提供可直接体验的小猫图案；图纸大小和最大颜色数量提供合理默认值。图片在本地转换，演示原型不会上传图片。

## 五个核心页面

1. 首页：醒目的「图片转拼豆」入口，直接体验示例，最近作品和原创灵感图案。
2. 转图编辑器：图纸预览、原图 / 像素 / 色号切换、网格大小、最多颜色、豆子尺寸、使用用量。调参后重新生成，支持背景移除、单格修色、撤销、图纸保存和 PNG 导出。
3. 豆子色卡：品牌与系列、按色号搜索、按色系筛选。点选颜色可查看色号、HEX、RGB 和相近颜色。演示版接入 MARD 221 色参考数据；其他品牌作为后续扩展设计，不展示虚构对应关系。
4. 跟拼模式：清晰的网格、行坐标和色号；按色号高亮、已拼行标记、自动记录进度、放大阅读、材料清单。真实的进度从已完成行计算，支持恢复。
5. 作品库：保存的图纸、未完成作品、收藏的原创示例；从保存作品继续编辑或跟拼。

## 视觉规范

温暖、安静、有手作质感。使用奶油白 #F8F7F2、森林绿 #355C48、鼠尾草 #E6EBDD、杏橙 #EFA980 和近黑 #29372E。颜色集中在作品与色卡，工具自身保持克制。

中文系统字体（PingFang SC / Microsoft YaHei）；标题 24–30 px，正文 14–16 px，辅助信息 11–13 px。数字使用等宽数字。卡片圆角 18–24 px，控件圆角 10–14 px；内容边距 20–24 px。主操作放在拇指容易够到的位置，按钮触摸区域至少 44 px。

微信顶部胶囊、手机状态栏和底部安全区在设计中保留；正式小程序使用微信原生状态栏、胶囊和真实 safe-area，避免重复绘制。

## Emil 设计原则的应用

- 优先清晰默认值、即时反馈和连续的编辑体验。
- 按钮按下 120 ms 缩放至 0.97；弹层进入 220 ms，退出 160 ms，使用 ease-out 自定义曲线。
- 高频画格、调色、标记进度立即响应；没有装饰性等待。
- 动效只改变 transform 和 opacity，支持 prefers-reduced-motion；鼠标 hover 仅在精确指针设备启用。
- 选中状态同时显示色号、描边和勾选，避免仅凭颜色辨认。
- 底部弹层可关闭，Escape 退出、焦点返回触发元素；提供可见键盘焦点。

## 转图与材料规则

网格提供 24 / 32 / 48 / 64 四档；保持图片长宽比，短边按比例计算。颜色数量提供 8 / 12 / 16 / 24 四档；透明格不计入豆子数量。用量为实际色号统计，不使用静态占位数字。

屏幕颜色属于近似值，以实体色卡为准。参考数据来源：https://github.com/HansBug/pindou-color-data/tree/main/mard-221-github 。品牌、系列、数据版本应独立存储；MARD 数据为公开参考数据，不作为官方色彩标准宣传。

成品尺寸 = 图纸格数 × 豆子间距，原型按 2.6 mm / 5 mm 估算。导出包含网格坐标、色号、每色用量、品牌系列和总数量。裁剪 / 对比度 / 感知色差优化属于正式开发深化项；原型提供可实际运行的基础匹配。

## 补充体验与异常状态

- 空作品库提供上传和示例入口。
- 不可解码的图片显示可理解的提示；保留之前的图案。
- 本地保存失败时提示，不显示保存成功。
- 已保存图纸与跟拼进度一起恢复；切换新图片时清空旧进度。
- 导出显示完成反馈；没有联网或登录也能体验。

## 交付边界与后续开发

本次交付为高保真浏览器交互原型、PNG 设计图和 UI / UX 说明，便于评审和微信小程序开发。原型不等同于已发布的小程序。

第一版小程序建议使用原生 Canvas 绘制图纸、wx.chooseMedia 选图、wx.saveImageToPhotosAlbum 导出、wx.setStorage 本地存储。后续再增加云端同步、自定义色卡、真实品牌套装、色号库存、PDF 分页打印和社区投稿。社区、商城和 AI 抠图不占用第一版主流程。
