### 本机日常启动

后端一个终端：

```sh
cd /Users/jkliang/Desktop/pindou
npm --prefix backend run dev
```

微信小程序编译另一个终端：

```sh
cd /Users/jkliang/Desktop/pindou

```

微信开发者工具打开 `/Users/jkliang/Desktop/pindou/dist/dev/mp-weixin`。不要把旧原型、dist/build 或其他项目导入成当前开发目录，也不要同时用 HBuilderX 和终端编译同一个输出目录。

- 后端最低 Node 版本为 `22.12`；具体依赖和命令以两个 `package.json` 为准。
- API 默认 `http://127.0.0.1:3001`；数据库为 `127.0.0.1:3306/bead_island`，专用应用账号 `bead_island_app`，不是 root。
- 后端配置在 `backend/.env`，微信 AppSecret 只能在后端。修改 `.env` 后需要手动重启后端。
- 管理员客户端配置在用户目录 `~/.local/etc/mysql/private/root-client.cnf`，不在仓库内的 `.local` 目录。不要把账号密码复制到交接消息、仓库或前端。
- `src/config.js` 从 `VITE_API_BASE_URL` 读取 API 地址，开发默认 localhost，正式包没有配置时不会退回 localhost；`cloudEnabled: false`。
- 微信本机 HTTP 调试曾获准仅在开发输出目录临时关闭合法域名校验；正式源码和发布设置保留校验。不要新开全局安全豁免。
- 手机的 127.0.0.1 是手机自身。局域网真机调试、HOST 绑定和生产 HTTPS 说明见 `docs/local-startup.md`，不得把 MySQL 对公网开放。

## 5. 已实现的功能与代码地图

以下为现有实现范围，不等于所有路径都已经真机验收通过。

- MySQL 保存图片 metadata、MARD 色号图纸、进度和公开作品数据，不保存图片二进制。

- 作品本地保留、后台自动保存、版本冲突保留副本。
- 入口：`backend/src/api.cjs`、`images.cjs`、`repository.cjs`、`storage.cjs`；前端 `src/lib/http.js`、`cloud.js`、`storage.js`、`work-store.js`、`auto-save.js`。

## 6. 最后两轮改动：不要回退

### A. 抠图显示与触摸区分离

用户反复反馈：图片跑到状态栏和导航上方，灰色编辑区空白，必须在图片下方拖动才会修改图像。此前几轮仅调整 padding、flex、canvas 定位或重新挂载，未解决。

实际复现时，原生 canvas 的布局矩形为 `left=15, top=102, width=345, height=455`，像素计算正确，但原生合成显示在顶部。最后一次改动彻底移除抠图模板中的可见原生 canvas：

- 用 OffscreenCanvas 计算，再用普通 image 层显示；显示与手势使用同一个 `.workspace` 普通 view 的实测矩形。
- 新增 `src/lib/cutout-preview.js` 双缓冲队列：待新帧 image load 后才切换，渲染请求合并，旧帧适时清理，释放后的迟到回调不能重现旧页面。
- 预览按编辑区分辨率生成；遮罩仍以原始输入尺寸处理和导出，不降低最终图纸精度。
- 更新 `tests/client-cutout-preview.test.cjs` 和 `tests/client-canvas-workspace.test.cjs`，另有触点扣除 view 原点后对应正确 mask 像素的用例。

### B. 导出格式卡片与所有按钮的果冻回弹（最近已批准并修改）

- `src/components/export-sheet.vue`：原来的扁平格式按钮改为两张等高圆角卡片，主副标题居中，选中绿边、浅绿底及右上角勾选。标题为“整张图纸 / 高清分块”，分块副标题显示实际张数；导出参数与业务逻辑不变。
